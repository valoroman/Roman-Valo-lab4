Варіант 3. Файл даних: house-price.json.
Формат наданого файлу: NDJSON.

## Встановлення і запуск

Потрібен Node.js 22 або новіший.

Встановлення залежностей: `npm ci`

Запуск:
`npm start -- -i house-price.json -h 127.0.0.1 -p 3000`

Режим розробки:
`npm run dev -- -i house-price.json -h 127.0.0.1 -p 3000`

Довідка: `node main.js --help`

## Параметри командного рядка

- -i, --input: обов'язковий шлях до даних.
- -h, --host: обов'язкова адреса сервера.
- -p, --port: обов'язковий порт від 1 до 65535.
- -o, --output: необов'язковий файл для запису відповіді.

Для збереження відповідей створити папку `mkdir -p output`
і додати до команди запуску `-o output/response.json`.
Кожна відповідь перезаписує попередню у цьому файлі.

## Запити GET

- / — усі будинки.
- /?furnished=true — лише повністю мебльовані.
- /?max_price=5000000 — ціна строго менша за 5000000.
- /?furnished=true&max_price=5000000 — обидва фільтри.

У curl адресу з параметрами потрібно брати в одинарні лапки.
Приклад:
`curl -i 'http://127.0.0.1:3000/?furnished=true&max_price=5000000'`

## Обробка даних і помилок

Файл читається заново під час кожного запиту до GET /.
Підтримуються JSON-масив і NDJSON.
Поля відповіді: price, area, furnishingstatus.
Числові рядки перетворюються на числа.

Записи з відсутніми, порожніми або некоректними обов'язковими
значеннями пропускаються. Порожній файл повертає [].
Фільтр furnished вмикається лише для точного значення true.
Порожній, нечисловий або нескінченний max_price повертає 400.

Коди HTTP:
- 200 — успішний запит, зокрема порожній результат.
- 400 — некоректний числовий параметр або URL.
- 404 — невідомий маршрут або метод.
- 500 — помилка читання, розбору даних або запису відповіді.

Помилки запитів обробляються без завершення сервера.
Операції з файлами виконуються через колбеки модуля fs.
